# Internationalization (i18n) Engine

IVIDS features a key-based internationalization architecture that applies dynamic multi-language translations instantaneously without requiring full page reloads.

## 🏗️ Architecture & Storage

1. **JSON Dictionaries**: Translation strings are stored in individual locale files under `app/src/main/assets/main/lang/*.json`.
2. **Base Key Rule**: New keys MUST be added to `en.json` first as the baseline dictionary.
3. **Automated Locale Batching**: Multi-language updates across all 32 locale files are automated using Python translation scripts in the agent `scratch/` folder.

## 💻 Usage Patterns

### HTML Attributes
Declaratively bind translation keys using `data-i18n`:
```html
<h1 data-i18n="nav.home">Home</h1>
<input data-i18n="search.placeholder" placeholder="Search movies...">
```

### JavaScript API
Access localized strings programmatically via `window.i18n`:
```javascript
const localizedText = window.i18n.t('settings.theme_updated');
```

### Dynamic DOM Scanning (`applyTranslations`)
Calling `i18n.applyTranslations(container)` scans the specified DOM sub-tree for `[data-i18n]` attributes and updates text content, placeholders, or image alt titles dynamically.
